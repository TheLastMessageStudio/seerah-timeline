# Photos locales

Les photos sous licence ouverte sont préparées par `python tools/download_place_images.py`.
Le script crée les fichiers image et `media_manifest.json`. Les fichiers réellement téléchargés
sont prioritaires dans l'application via `imageAsset`. Ne jamais supprimer les crédits, licences
ou URL de provenance enregistrés dans `assets/data/places.json`.
