# Calendrier éditorial prévisionnel — 15 semaines

Cadence : **5 fiches par semaine** (dernier lot de 4), pour couvrir les 74 événements qui restent à programmer après les cinq fiches du lot 01 déjà disponibles. Le lot 02, déjà enrichi, est planifié au 16 novembre 2026 et reste verrouillé jusque-là. Les dates sont des jalons éditoriaux, pas une promesse de publication automatique sur les stores. Le calendrier complet est dans `assets/data/release_schedule.json`.

Le statut `needs_corroboration` est conservé tant qu’une revue éditoriale indépendante n’a pas été faite.
